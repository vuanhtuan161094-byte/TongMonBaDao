## Translate to current G1 — no new gameplay authority

1. **Map tells the story**: actual building instance, worker, planned batch, remaining scheduler tick-time and percentage; preserve source-verified art and stand/walk if only those clips exist.
2. **Actionable focused panel**: tap a real site, see worker and real progress at the top, assign/replace/start via existing Workforce commands, avoid menu scavenger hunt.
3. **Earned visual feedback**: distinguish “Mẻ ×N đang làm” from cumulative “Đã nhập kho N”; only backend Warehouse settlement may produce `+N` delivery feedback.
4. **Readable quiet map**: selected and active sites first; avoid big overlapping floating cards. Keep badge apparent size roughly constant while camera zooms, clamp to visible view, and keep dormant sites mostly in production board rather than plastered across the map.
5. **Disciple presence**: Source A existing stand/walk is real; no fabricated mining/chopping/sowing swing. Exact worksite anchor is visual only; no travel simulation, mining animation tick, yield timer or carry cycle should affect warehouse arithmetic.
