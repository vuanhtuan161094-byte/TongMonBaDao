# P0 SPEC — Simulation Sandbox

## Question P0 must answer

Can six disciples autonomously live inside a minimal sect economy and produce a stable, observable, differentiated simulation loop?

## World

- Sect hub
- Thanh Trúc Lâm — danger 1
- Bạch Thạch Khê — danger 2
- Hắc Phong Cốc — danger 3

## Disciple behavior profiles

1. Lâm Thanh Vũ — aggressive, high risk.
2. Trần Mặc — defensive, low risk.
3. Bạch Nguyệt — balanced ranged profile.
4. Lâm An — profit/safety weighted.
5. Cố Trường Phong — extreme risk/combat.
6. Triệu Linh Nhi — survival/support weighted.

## P0 gates

G1 Runtime: bounded unattended run without crash/stuck.
G2 Autonomous loop: hunt and recovery loop complete.
G3 Economy: transfer correctness + money conservation.
G4 Behavioral difference: high-risk and low-risk profiles produce measurably different region choices/retreat behavior.
G5 Recovery: injury leads to return/heal/rest and re-entry.
G6 Save: round-trip preserves state and simulation remains valid.
G7 Debuggability: selected agent exposes current action, scores and decision reason.

All seven must be green before opening P1.
