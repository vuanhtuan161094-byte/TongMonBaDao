# 1. Player-facing rule

A Spiritual Root is not only a technique requirement.

Investing in it must visibly make the disciple stronger.

Each owned root has an integer purity from **1 to 100**. A higher value grants:
- faster cultivation for matching elemental cultivation;
- faster learning/mastery for matching elemental techniques/skills;
- stronger numeric effects from matching elemental skills;
- resistance to matching elemental incoming damage;
- one permanent passive characteristic of that base element.

When one or more roots reach exactly 100, the disciple gains **Spiritual Root Resonance**. Resonance amplifies every bonus generated by all owned base roots.

Therefore:
- one perfected root is immediately powerful;
- two/three/four perfected roots add further power;
- five roots at 100/100/100/100/100 are intentionally an extremely powerful long-term build.

Birth determines starting cost/time, not the universal final ceiling.

---

# 2. Canonical base roots

Exactly five base roots:

- Kim / Metal;
- Mộc / Wood;
- Thủy / Water;
- Hỏa / Fire;
- Thổ / Earth.

Ordinary recruitment has **1–5 distinct base roots**.
There is no ordinary zero-root result.

No base element is globally rarer than another.
After root count is chosen, elements are sampled uniformly without replacement.

Wind/Lightning/Ice/Yang/Nether or other exotic roots are mutation/transformation content and are not part of the ordinary base-element roll.

# 3. Birth root-count distribution

Starting canonical ordinary distribution:

| Root count | Rate |
|---|---:|
| 1 | 7% |
| 2 | 18% |
| 3 | 30% |
| 4 | 28% |
| 5 | 17% |

Why this curve:
- one root is uncommon and gives strong early specialization;
- 3–4 roots are the ordinary center of the population;
- five roots are not a trash rarity and occur often enough to support long-term all-element builds;
- root count is independent from Disciple Quality/Lục Duy quality.

Dẫn Tiên Main-guide Mị Lực does **not** silently alter these Spiritual Root rates.
Chiêu Mộ Lệnh uses the same whole-person root-generation authority.
A future root-specialized recruitment building/event may explicitly bias the table, but must declare that rule.

# 4. Birth purity distribution

Every owned element rolls its own purity independently.

Canonical integer range:
**1–100**.

There is no one global purity shared by all roots.

Starting deterministic distribution:

`purity = clamp(round(100 × U^E), 1, 100)`

where:
- `U` is that root's deterministic seeded random value in 0..1;
- `E` depends on birth root count.

| Birth root count | E | Approx. mean purity |
|---|---:|---:|
| 1 | 0.45 | ~69 |
| 2 | 0.70 | ~59 |
| 3 | 1.00 | ~50 |
| 4 | 1.50 | ~40 |
| 5 | 2.30 | ~30 |

Important:
- this is a **birth distribution**, not a post-birth cap;
- every count retains a rare high-purity tail;
- a five-root disciple may still be born with an unusually strong individual root;
- all owned roots can later reach 100 through permanent investment.

Root count and Disciple Quality remain independent.

# 5. Canonical stored data

Future V2 character state should persist root authority directly on the person.

Target fields:

`spiritual_root_model_version = 2`

`spiritual_root_values = { "metal": int, "wood": int, ... }`

Only owned elements are present in `spiritual_root_values`.

Also persist immutable birth history:

`spiritual_root_birth_values = { ... }`

Derived values are **not stored as independent truth**:
- current root count = number of keys;
- perfected root count = number of roots whose current purity is 100;
- resonance multiplier = derived from perfected root count;
- root-generated stat bonuses = derived at runtime.

Do not store copied bonus percentages that can desynchronize from purity.

Legacy fields:
- `spiritual_root_elements`;
- one global `spiritual_root_purity`;
- `spiritual_root_quality`;

become migration/compatibility fields only once V2 is implemented. They must no longer be final gameplay authority.

# 6. Universal per-root buffs

For an owned root of purity `P`, first derive the resonance multiplier `R` from section 8.

The root contributes:

`matching_cultivation_bonus = P × 0.30% × R`

`matching_mastery_bonus = P × 0.15% × R`

`matching_skill_effect_bonus = P × 0.30% × R`

`matching_element_resistance = P × 0.15% × R`

At P=100 before resonance:
- +30% matching elemental cultivation;
- +15% matching elemental learning/mastery;
- +30% matching elemental skill effect;
- +15% matching-element resistance.

These are **starting balance constants**. The architecture is locked; later benchmark changes must be deliberate and documented.

## 6.1 Cultivation

The cultivation bonus applies when the actual cultivation technique/activity uses that element.

Same-channel percentage bonuses remain additive on the base:
`final_gain = base × (1 + aptitude_bonus + root_bonus + technique_bonus + ...)`.

Fixed +X consumables are not multiplied unless the content explicitly says so.

## 6.2 Learning/mastery

Matching-root mastery bonus applies to learning/mastery XP for techniques/skills tagged with that element.

It intentionally may coexist with Thông Tuệ.
The player may invest in both and receive both benefits.

Same-channel mastery bonuses add on base rather than chain-multiply.

## 6.3 Skill effect

The root does not decide what the skill does.

Burn, Freeze, Guard, Weaken, Heal, Shield, Dash, Summon and other mechanics belong to the **skill definition**.

A skill declares which numeric fields are root-scalable.
Default scalable channels should include:
- direct damage;
- skill-owned damage over time;
- healing;
- shielding;
- other explicit magnitude values.

Do not automatically scale:
- cooldown;
- cast time;
- movement distance;
- debuff duration;
- status type;
- fixed values explicitly marked non-scaling.

This prevents every Fire skill from being forced to Burn, every Water skill from being forced to Slow, etc.

# 7. Base-element permanent passives

In addition to the universal matching-element bonuses, each base root contributes one permanent combat characteristic.

All values below use `P × coefficient × R`.

| Root | Permanent passive | Coefficient |
|---|---|---:|
| Kim | Defense penetration | +0.10% / purity |
| Mộc | Max HP | +0.12% / purity |
| Thủy | Attack speed AND cast speed | +0.08% / purity to each |
| Hỏa | All damage dealt | +0.10% / purity |
| Thổ | Defense | +0.12% / purity |

These passives remain active even when the disciple currently uses a skill of another element.

They are intentionally real combat power, not cosmetic identity.

## 7.1 Runtime ownership of each passive

- **Kim / penetration** enters the future canonical Defense-resolution channel before target Defense reduces damage.
- **Mộc / Max HP** enters derived max-HP percentage bonuses. When permanent max HP changes, preserve current HP ratio rather than healing to full for free.
- **Thủy / attack speed** modifies basic-attack interval through the canonical attack-speed channel.
- **Thủy / cast speed** modifies cast time through the separate canonical cast-speed channel. It does not silently change movement speed or cooldown.
- **Hỏa / damage dealt** enters the canonical outgoing-damage percentage channel and affects owned direct/DoT damage unless content explicitly excludes it.
- **Thổ / Defense** enters derived Defense percentage bonuses.

Final Combat Stats V2 still owns the final ATK/DEF/HP/penetration formulas. Spiritual Root V2 owns the **contribution amount** above and must plug into that authority rather than inventing a parallel combat stat model.

# 8. Perfected-root resonance — 1/2/3/4/5 roots at 100

A root is **perfected** only at purity exactly 100.

Let `N` be the number of perfected base roots.

| N | Display concept | Total resonance bonus | R |
|---:|---|---:|---:|
| 0 | Chưa cộng hưởng | 0% | 1.00 |
| 1 | Nhất Mạch Viên Mãn | +10% root-buff effectiveness | 1.10 |
| 2 | Song Mạch Cộng Minh | +25% | 1.25 |
| 3 | Tam Mạch Hợp Lưu | +45% | 1.45 |
| 4 | Tứ Tượng Chu Thiên | +70% | 1.70 |
| 5 | Ngũ Hành Viên Mãn | +100% | 2.00 |

The table is **not cumulative multiplication**.
For example two perfected roots use R=1.25, not 1.10×1.25.

Resonance scales every bonus generated by owned base roots:
- elemental cultivation;
- elemental mastery;
- elemental skill effect;
- elemental resistance;
- Kim/Mộc/Thủy/Hỏa/Thổ permanent passives.

It does not multiply unrelated equipment/trait/realm bonuses.

## 8.1 Full five-root result

At 100/100/100/100/100, R=2.00.

The root system alone contributes approximately:

- +60% matching skill effect for every base element;
- +60% matching elemental cultivation;
- +30% matching elemental mastery;
- +30% resistance to each of the five base elements;
- Kim: +20% Defense penetration;
- Mộc: +24% Max HP;
- Thủy: +16% attack speed and +16% cast speed;
- Hỏa: +20% all damage dealt;
- Thổ: +24% Defense.

This is intentionally very strong.
Reaching it requires all five roots to exist and all five to be permanently raised to 100.

# 9. Elemental combat matchup

Elemental matchup is combat-core data, not copied into every skill.

Counter cycle:

- Kim khắc Mộc;
- Mộc khắc Thổ;
- Thổ khắc Thủy;
- Thủy khắc Hỏa;
- Hỏa khắc Kim.

Starting matchup constants:

- attacking an element you counter: **×1.25 elemental effect/damage**;
- attacking while your skill element is countered by the target element: **×0.85**;
- same element or no counter relation: **×1.00** before explicit resistance;
- neutral/non-elemental attacks: **×1.00**.

Elemental matchup is a distinct content relation and may multiply after same-channel percentage bonuses.

Monster/content authority must expose:
- a primary element or neutral;
- optional explicit elemental resistances;
- later multi-element phases if content requires them.

Do not globally force same-element attacks to be weak merely because the colors match; explicit resistance/content handles that.

# 10. Combat examples

Example A — single perfected Fire root:

Hỏa 100, one perfected root -> R=1.10.

Root contributions:
- Fire skill effect +33%;
- Fire resistance +16.5%;
- matching Fire cultivation +33%;
- matching Fire mastery +16.5%;
- all damage dealt +11%.

A Fire damage skill therefore receives both its elemental-skill contribution and the Hỏa global damage contribution in their relevant channels.

Against a Metal monster, the Fire-vs-Metal matchup then applies ×1.25.

Example B — full five roots:

100/100/100/100/100 -> R=2.00.

A Fire skill gets +60% root skill effect plus the +20% Hỏa all-damage passive.
A Water skill gets the same +60% root skill effect while the disciple still retains every permanent passive from Kim/Mộc/Thủy/Hỏa/Thổ.

This is why the full-five build is a real late-game power fantasy rather than merely “can equip more techniques”.

# 11. Multi-element techniques

A technique may require more than one root.

For a multi-element compatibility check, use all required roots.
A starting effective-purity rule is:

`effective_purity = 60% × weakest_required_root + 40% × average_required_roots`

This prevents one 100 root from carrying several weak roots through an advanced multi-element technique.

True multi-element combat skills should explicitly define their element components/weights.
Do not silently choose whichever element gives the best matchup.

# 12. Refinement after recruitment

Ordinary refinement:
- targets one existing root;
- is deterministic;
- increases exactly +1 purity;
- cannot fail;
- does not add/remove another element;
- cannot exceed 100.

Primary ordinary material:
**Linh Tủy** — already a canonical stackable resource in Resource Registry.

Starting cost per +1:

| Current purity | Linh Tủy cost |
|---|---:|
| 1–39 | 1 |
| 40–59 | 2 |
| 60–79 | 4 |
| 80–89 | 8 |
| 90–94 | 16 |
| 95–98 | 32 |
| 99 -> 100 | 64 + 1 Ngũ Hành Bản Nguyên |

There is no diminishing return in the gained point.
Higher purity costs more resources; the reward from the next purity point remains fully real.

# 13. Adding a missing base root

A missing base root can eventually be created after recruitment.
This preserves the “one disciple can be nurtured forever” law.

It is a major transformation, not ordinary refinement.

New canonical high-tier resource:
**Ngũ Hành Bản Nguyên**.

Starting transformation costs:

| Current root count -> new count | Linh Tủy | Ngũ Hành Bản Nguyên | New root starts at |
|---|---:|---:|---:|
| 1 -> 2 | 128 | 1 | 10 |
| 2 -> 3 | 256 | 2 | 10 |
| 3 -> 4 | 512 | 4 | 10 |
| 4 -> 5 | 1024 | 8 | 10 |

The player explicitly selects which missing base element is created.

Transformation is deterministic once materials/conditions are met.
No hidden reroll.

Birth remains valuable because a character born with more/high-purity roots skips enormous cost.

# 14. Resource source contract

A consumer may not ship without an acquisition path.

## Linh Tủy

Primary intended sources:
- elite/boss hunting loot;
- explicit higher-tier region/secret-realm loot tables;
- later limited market/auction/content rewards if declared.

The existing `linh_tuy` resource is already registered, but current live gameplay does not yet provide a complete canonical source loop.

Therefore Root V2 implementation must add at least one real Linh Tủy acquisition source **in the same implementation phase before refinement is exposed to players**.

Starting content target:
- elite: roughly 20% chance for 1;
- boss: guaranteed 2–4;
- rare/world boss: guaranteed 5–10.

Exact monster tables belong to monster/region content data, not hardcoded inside RootRefinementSystem.

## Ngũ Hành Bản Nguyên

This resource does not exist in the live registry yet.

It must be added only together with real sources.

Starting intended sources:
- first-clear reward of eligible elemental/root-themed high-tier bosses or secret realms;
- repeat eligible boss: low single-digit chance;
- rare/world boss or major fortune content: materially higher chance;
- later auction/sect-event sources may be explicit.

Starting benchmark target:
- eligible repeat boss: ~5%;
- rare/world eligible boss: ~25%;
- designated first clear: 1 guaranteed.

It is used for:
- 99 -> 100 perfection;
- creating a missing base root;
- later mutation/transformation only if that future spec explicitly consumes it.

# 15. Generation, identity and persistence

Spiritual Root is part of whole-person generation.

Same:
`world seed + recruitment source + generation index`

must reproduce:
- root count;
- chosen elements;
- each root's birth purity;
- future latent mutation identity when that subsystem is designed.

Accepting a candidate must preserve root identity exactly.
Reveal must never reroll hidden values.
Save/load must preserve current and birth root values exactly.

Disciple Quality does not summarize or override Spiritual Root value.

# 16. Current live-code migration requirements

Current live code is legacy and intentionally differs from this V2 design:

- one global purity currently drives all owned elements;
- legacy quality mixes purity and element count;
- root refinement currently caps at 0.98 and uses diminishing gain;
- root refinement currently uses old Potential in gain;
- current root code changes breakthrough chance;
- current root code changes technique mastery/effect through legacy multipliers;
- current combat skills already carry one `element` tag and read root technique effect;
- current monsters have HP/power/loot but no canonical element/resistance;
- current combat has no final ATK/DEF/HP V2 authority yet.

When implementation is authorized, migrate rather than create a second root system.

V2 must:
- replace global purity with per-element values;
- remove ordinary diminishing-gain refinement;
- stop using old Potential as refinement gain;
- stop generic root breakthrough modifiers unless later content explicitly adds one;
- make root count independent from purity/quality;
- extend combat/monster data for actual elemental matchup;
- route unique passives into final combat-stat authority;
- preserve deterministic saves and old-save migration.

No code change is authorized by this document alone.

# 17. UI/readability requirements

Roster summary should stay compact even for 1,000–3,000 disciples.

Example:
`Hỏa 100 · Mộc 63 · Thủy 41 | Cộng Hưởng 1/5`

Detail view may show:
- current purity and birth purity;
- current per-root buffs;
- perfected-root count and next resonance milestone;
- Linh Tủy / Bản Nguyên cost to next point/milestone;
- compatible techniques;
- elemental resistances/passives.

Filters should support:
- has element;
- purity >= X;
- perfected element;
- perfected-root count;
- full five-root;
- compatible with technique/content.

Do not require the player to open every disciple individually.

# 18. Reference adaptation

Useful reference lessons:
- 《最强祖师》 makes root progression increase corresponding elemental power and base combat value, and its single-vs-multi structure creates meaningful specialization.
- 《觅长生》 demonstrates that elemental-root weight/compatibility can meaningfully shape how a character uses elemental power.
- 《修仙家族模拟器》 demonstrates the danger of making multi-root characters permanently inferior through global cultivation/breakthrough penalties.

Project adaptation:
- keep visible combat/cultivation value;
- keep single-root early specialization;
- allow multi-root breadth and eventual full-five supremacy through enormous investment;
- do not copy another game's fixed total-root-level cap or permanent “five roots = trash” ceiling.
