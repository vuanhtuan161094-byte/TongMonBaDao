# 1. Player-facing rule

A Spiritual Root is not only a technique requirement.

Investing in it must visibly make the disciple stronger.

Each owned root has an integer purity from **1 to 100**. A higher value grants:
- faster cultivation for matching elemental cultivation;
- faster learning/mastery for matching elemental techniques/skills;
- stronger numeric effects from matching elemental skills;
- resistance to matching elemental incoming damage;
- one permanent passive characteristic of that base element.

When one or more roots reach exactly 100, the disciple gains **Spiritual Root Resonance**. Resonance amplifies every bonus generated by all owned base roots.

Therefore:
- one perfected root is immediately powerful;
- two/three/four perfected roots add further power;
- five roots at 100/100/100/100/100 are intentionally an extremely powerful long-term build.

Birth determines starting cost/time, not the universal final ceiling.

# 2. Canonical base roots

Exactly five base roots:

- Kim / Metal;
- Mộc / Wood;
- Thủy / Water;
- Hỏa / Fire;
- Thổ / Earth.

Ordinary recruitment has **1–5 distinct base roots**.
There is no ordinary zero-root result.

No base element is globally rarer than another.
After root count is chosen, elements are sampled uniformly without replacement.

Wind/Lightning/Ice/Yang/Nether or other exotic roots are mutation/transformation content and are not part of the ordinary base-element roll.

# 4. Birth purity distribution

Every owned element rolls its own purity independently.

Canonical integer range:
**1–100**.

There is no one global purity shared by all roots.

Starting deterministic distribution:

`purity = clamp(round(100 × U^E), 1, 100)`

where:
- `U` is that root's deterministic seeded random value in 0..1;
- `E` depends on birth root count.

| Birth root count | E | Approx. mean purity |
|---|---:|---:|
| 1 | 0.45 | ~69 |
| 2 | 0.70 | ~59 |
| 3 | 1.00 | ~50 |
| 4 | 1.50 | ~40 |
| 5 | 2.30 | ~30 |

Important:
- this is a **birth distribution**, not a post-birth cap;
- every count retains a rare high-purity tail;
- a five-root disciple may still be born with an unusually strong individual root;
- all owned roots can later reach 100 through permanent investment.

Root count and Disciple Quality remain independent.

# 6. Universal per-root buffs

For an owned root of purity `P`, first derive the resonance multiplier `R` from section 8.

The root contributes:

`matching_cultivation_bonus = P × 0.30% × R`

`matching_mastery_bonus = P × 0.15% × R`

`matching_skill_effect_bonus = P × 0.30% × R`

`matching_element_resistance = P × 0.15% × R`

At P=100 before resonance:
- +30% matching elemental cultivation;
- +15% matching elemental learning/mastery;
- +30% matching elemental skill effect;
- +15% matching-element resistance.

These are **starting balance constants**. The architecture is locked; later benchmark changes must be deliberate and documented.

## 6.1 Cultivation

The cultivation bonus applies when the actual cultivation technique/activity uses that element.

Same-channel percentage bonuses remain additive on the base:
`final_gain = base × (1 + aptitude_bonus + root_bonus + technique_bonus + ...)`.

Fixed +X consumables are not multiplied unless the content explicitly says so.

## 6.2 Learning/mastery

Matching-root mastery bonus applies to learning/mastery XP for techniques/skills tagged with that element.

It intentionally may coexist with Thông Tuệ.
The player may invest in both and receive both benefits.

Same-channel mastery bonuses add on base rather than chain-multiply.

## 6.3 Skill effect

The root does not decide what the skill does.

Burn, Freeze, Guard, Weaken, Heal, Shield, Dash, Summon and other mechanics belong to the **skill definition**.

A skill declares which numeric fields are root-scalable.
Default scalable channels should include:
- direct damage;
- skill-owned damage over time;
- healing;
- shielding;
- other explicit magnitude values.

Do not automatically scale:
- cooldown;
- cast time;
- movement distance;
- debuff duration;
- status type;
- fixed values explicitly marked non-scaling.

This prevents every Fire skill from being forced to Burn, every Water skill from being forced to Slow, etc.

# 7. Base-element permanent passives

In addition to the universal matching-element bonuses, each base root contributes one permanent combat characteristic.

All values below use `P × coefficient × R`.

| Root | Permanent passive | Coefficient |
|---|---|---:|
| Kim | Defense penetration | +0.10% / purity |
| Mộc | Max HP | +0.12% / purity |
| Thủy | Attack speed AND cast speed | +0.08% / purity to each |
| Hỏa | All damage dealt | +0.10% / purity |
| Thổ | Defense | +0.12% / purity |

These passives remain active even when the disciple currently uses a skill of another element.

They are intentionally real combat power, not cosmetic identity.

## 7.1 Runtime ownership of each passive

- **Kim / penetration** enters the future canonical Defense-resolution channel before target Defense reduces damage.
- **Mộc / Max HP** enters derived max-HP percentage bonuses. When permanent max HP changes, preserve current HP ratio rather than healing to full for free.
- **Thủy / attack speed** modifies basic-attack interval through the canonical attack-speed channel.
- **Thủy / cast speed** modifies cast time through the separate canonical cast-speed channel. It does not silently change movement speed or cooldown.
- **Hỏa / damage dealt** enters the canonical outgoing-damage percentage channel and affects owned direct/DoT damage unless content explicitly excludes it.
- **Thổ / Defense** enters derived Defense percentage bonuses.

Final Combat Stats V2 still owns the final ATK/DEF/HP/penetration formulas. Spiritual Root V2 owns the **contribution amount** above and must plug into that authority rather than inventing a parallel combat stat model.

# 8. Perfected-root resonance — 1/2/3/4/5 roots at 100

A root is **perfected** only at purity exactly 100.

Let `N` be the number of perfected base roots.

| N | Display concept | Total resonance bonus | R |
|---:|---|---:|---:|
| 0 | Chưa cộng hưởng | 0% | 1.00 |
| 1 | Nhất Mạch Viên Mãn | +10% root-buff effectiveness | 1.10 |
| 2 | Song Mạch Cộng Minh | +25% | 1.25 |
| 3 | Tam Mạch Hợp Lưu | +45% | 1.45 |
| 4 | Tứ Tượng Chu Thiên | +70% | 1.70 |
| 5 | Ngũ Hành Viên Mãn | +100% | 2.00 |

The table is **not cumulative multiplication**.
For example two perfected roots use R=1.25, not 1.10×1.25.

Resonance scales every bonus generated by owned base roots:
- elemental cultivation;
- elemental mastery;
- elemental skill effect;
- elemental resistance;
- Kim/Mộc/Thủy/Hỏa/Thổ permanent passives.

It does not multiply unrelated equipment/trait/realm bonuses.

## 8.1 Full five-root result

At 100/100/100/100/100, R=2.00.

The root system alone contributes approximately:

- +60% matching skill effect for every base element;
- +60% matching elemental cultivation;
- +30% matching elemental mastery;
- +30% resistance to each of the five base elements;
- Kim: +20% Defense penetration;
- Mộc: +24% Max HP;
- Thủy: +16% attack speed and +16% cast speed;
- Hỏa: +20% all damage dealt;
- Thổ: +24% Defense.

This is intentionally very strong.
Reaching it requires all five roots to exist and all five to be permanently raised to 100.

# 9. Elemental combat matchup

Elemental matchup is combat-core data, not copied into every skill.

Counter cycle:

- Kim khắc Mộc;
- Mộc khắc Thổ;
- Thổ khắc Thủy;
- Thủy khắc Hỏa;
- Hỏa khắc Kim.

Starting matchup constants:

- attacking an element you counter: **×1.25 elemental effect/damage**;
- attacking while your skill element is countered by the target element: **×0.85**;
- same element or no counter relation: **×1.00** before explicit resistance;
- neutral/non-elemental attacks: **×1.00**.

Elemental matchup is a distinct content relation and may multiply after same-channel percentage bonuses.

Monster/content authority must expose:
- a primary element or neutral;
- optional explicit elemental resistances;
- later multi-element phases if content requires them.

Do not globally force same-element attacks to be weak merely because the colors match; explicit resistance/content handles that.

# 10. Combat examples

Example A — single perfected Fire root:

Hỏa 100, one perfected root -> R=1.10.

Root contributions:
- Fire skill effect +33%;
- Fire resistance +16.5%;
- matching Fire cultivation +33%;
- matching Fire mastery +16.5%;
- all damage dealt +11%.

A Fire damage skill therefore receives both its elemental-skill contribution and the Hỏa global damage contribution in their relevant channels.

Against a Metal monster, the Fire-vs-Metal matchup then applies ×1.25.

Example B — full five roots:

100/100/100/100/100 -> R=2.00.

A Fire skill gets +60% root skill effect plus the +20% Hỏa all-damage passive.
A Water skill gets the same +60% root skill effect while the disciple still retains every permanent passive from Kim/Mộc/Thủy/Hỏa/Thổ.

This is why the full-five build is a real late-game power fantasy rather than merely “can equip more techniques”.

# 11. Multi-element techniques

A technique may require more than one root.

For a multi-element compatibility check, use all required roots.
A starting effective-purity rule is:

`effective_purity = 60% × weakest_required_root + 40% × average_required_roots`

This prevents one 100 root from carrying several weak roots through an advanced multi-element technique.

True multi-element combat skills should explicitly define their element components/weights.
Do not silently choose whichever element gives the best matchup.

# 12. Refinement after recruitment

Ordinary refinement:
- targets one existing root;
- is deterministic;
- increases exactly +1 purity;
- cannot fail;
- does not add/remove another element;
- cannot exceed 100.

Primary ordinary material:
**Linh Tủy** — already a canonical stackable resource in Resource Registry.

Starting cost per +1:

| Current purity | Linh Tủy cost |
|---|---:|
| 1–39 | 1 |
| 40–59 | 2 |
| 60–79 | 4 |
| 80–89 | 8 |
| 90–94 | 16 |
| 95–98 | 32 |
| 99 -> 100 | 64 + 1 Ngũ Hành Bản Nguyên |

There is no diminishing return in the gained point.
Higher purity costs more resources; the reward from the next purity point remains fully real.

A missing base root can eventually be created after recruitment.
This preserves the “one disciple can be nurtured forever” law.

It is a major transformation, not ordinary refinement.

New canonical high-tier resource:
**Ngũ Hành Bản Nguyên**.

Starting transformation costs:

| Current root count -> new count | Linh Tủy | Ngũ Hành Bản Nguyên | New root starts at |

| 1 -> 2 | 128 | 1 | 10 |
| 2 -> 3 | 256 | 2 | 10 |

The player explicitly selects which missing base element is created.

Transformation is deterministic once materials/conditions are met.
No hidden reroll.

Birth remains valuable because a character born with more/high-purity roots skips enormous cost.

Current live code is legacy and intentionally differs from this V2 design:

- one global purity currently drives all owned elements;
- legacy quality mixes purity and element count;
- root refinement currently caps at 0.98 and uses diminishing gain;

# 19. Dị Linh Căn V2 — locked identity model

Dị Linh Căn is a rare transformation layer attached to an existing base root.

V1 branches:

| Base root | Mutation V1 | Combat identity |
|---|---|---|
| Kim | Lôi | burst / secondary lightning strikes |
| Mộc | Phong | mobility / skill rotation |
| Thủy | Băng | stacking control |
| Hỏa | Dương | DoT -> burst conversion |
| Thổ | U Minh | survival / lethal interception |

The data model must allow future additional branches.
Do not hardcode the schema as if Metal can only ever have Lightning forever.

Canonical Dị-Căn display states:
- **Tiềm Ẩn** — identity exists but is unrevealed/inactive;
- **Hiển Lộ** — identity has been revealed but is not yet awakened; this is a discovery state, not a power realm;
- **Thức Tỉnh** — first active realm;
- **Thuế Biến** — deeper mutation realm;
- **Viên Mãn** — completed mutation realm.

Stable internal enum IDs:
- `latent`;
- `awakened`;
- `metamorphosis`;
- `perfected`.

Player-facing text must use the Vietnamese cultivation names above rather than Roman numerals.

A mutation:
- does **not** replace the base root;
- does **not** remove base compatibility;
- does **not** have a second purity meter;
- may progress through Thức Tỉnh / Thuế Biến / Viên Mãn;
- may coexist with mutations on the disciple's other base roots;
- remains independent from Disciple Quality.

Example:
`Kim 100 · Lôi Viên Mãn`

still counts as:
- Kim 100 for base-root Resonance;
- Kim for the five-element counter relationship;
- compatible with ordinary Kim content;
- additionally compatible with Lôi content.

| Birth result | Rate |
|---|---:|

| One latent mutation | 0.19% |

# 22. Reveal, awakening and acquired mutation

## 22.1 Congenital latent path

Reveal:
- associated base-root purity reaches **70**;
- if a congenital latent mutation's associated root is already >=70 at birth, it is **Hiển Lộ immediately when that person's generated profile is finalized**;
- reveal is deterministic;
- no resource cost;
- no success roll;
- Hiển Lộ grants no mutation combat buff until Thức Tỉnh.

Thức Tỉnh awakening:
- associated base root >=80;
- **64 Linh Tủy**;
- **1 matching Dị Bản Nguyên**.

Thuế Biến:
- associated base root >=90;
- **128 Linh Tủy**;
- **2 matching Dị Bản Nguyên**.

Viên Mãn:
- associated base root =100;
- **256 Linh Tủy**;
- **4 matching Dị Bản Nguyên**;
- **1 Ngũ Hành Bản Nguyên**.

All transitions are deterministic.

## 22.2 No congenital latent mutation

A favorite disciple may still acquire a mutation later.

Requirement:
- associated base root =100.

Create Thức Tỉnh:
- **256 Linh Tủy**;
- **3 matching Dị Bản Nguyên**;
- **1 Ngũ Hành Bản Nguyên**.

Then **Thuế Biến / Viên Mãn** use the normal costs above.

Therefore congenital mutation saves enormous time/resources but does not create a permanent final ceiling.

# 26. Global mutation-proc safety law

Mutation mechanics are powerful rule changes.

To prevent recursive proc loops:

**A secondary effect created by a Mutation mechanic does not trigger another Mutation mechanic unless a future content rule explicitly opts in.**

Therefore by default:
- Thiên Lôi cannot summon another Thiên Lôi;
- Thiên Lôi does not add Hàn Ấn;
- Dương Bạo does not trigger Thiên Lôi;
- Hàn Ấn/Băng Phong does not count as a new Băng skill cast;
- DoT ticks do not independently trigger mutation mechanics;
- reflected damage does not trigger mutation mechanics.

Every mutation mechanic must use a real combat source/cast identity.

# 27. Lôi Linh Căn — locked combat mechanic

Buff vĩnh viễn theo cảnh giới:

| Cảnh giới | Crit Rate contribution | Crit Damage contribution |
|---|---:|---:|
| **Thức Tỉnh** | +5 percentage points | +15% |
| **Thuế Biến** | +10 percentage points | +30% |
| **Viên Mãn** | +15 percentage points | +50% |

These contributions require future canonical Crit/Crit-Damage combat-stat authority.
Do not invent a root-only private Crit formula.

## 27.1 Thiên Lôi

Thiên Lôi is event-driven, not a free periodic timer.

At encounter start it is ready.

When a **Lôi-tagged direct-damage skill** hits and Thiên Lôi is ready:
- trigger once for that cast;
- then start the internal cooldown.

| Cảnh giới | Internal cooldown | Primary Thiên Lôi damage |
|---|---:|---:|
| **Thức Tỉnh** | 6s | 30% of the triggering hit |
| **Thuế Biến** | 5s | 50% |
| **Viên Mãn** | 4s | 80% |

AoE:
- one cast still triggers at most one primary Thiên Lôi;
- Thuế Biến may chain to 1 additional nearby target at 70% of Thiên Lôi damage;
- Viên Mãn may chain to 2 additional nearby targets at 70% then 50%.

Multi-hit:
- one cast may trigger at most one Thiên Lôi regardless of hit count.

Basic attack:
- ordinary basic attacks do not trigger Thiên Lôi;
- a skill/technique may explicitly tag empowered basics as Lôi, after which the same internal cooldown and one-trigger rule applies.

Thiên Lôi itself:
- does not crit by default;
- cannot trigger Mutation procs;
- remains useful against a single boss through the primary strike even when no chain target exists.

---

# 28. Phong Linh Căn — locked combat mechanic

Buff vĩnh viễn theo cảnh giới:

| Cảnh giới | Movement Speed | Cast Speed |
|---|---:|---:|
| **Thức Tỉnh** | +10% | +5% |
| **Thuế Biến** | +20% | +10% |
| **Viên Mãn** | +30% | +15% |

Movement speed remains the canonical movement stat.
Therefore it may naturally reduce real travel/hauling overhead in systems that already consume Movement Speed.
It does **not** become a generic profession-work-speed multiplier.

## 28.1 Phong Thế

When a **Phong-tagged combat skill** is successfully cast and Phong Thế is ready:
- gain one Phong Thế;
- Phong Thế lasts **5 seconds**;
- it does not stack.

The next **different combat skill** used during that window consumes Phong Thế.
That use receives a one-cast cooldown reduction:

| Cảnh giới | Cooldown reduction on the consumed skill |
|---|---:|
| **Thức Tỉnh** | 15% |
| **Thuế Biến** | 25% |
| **Viên Mãn** | 35% |

Internal cooldown for creating a new Phong Thế:

| Cảnh giới | Internal cooldown |
|---|---:|
| **Thức Tỉnh** | 8s |
| **Thuế Biến** | 7s |
| **Viên Mãn** | 6s |

Order:
1. ordinary cooldown modifiers resolve;
2. Phong Thế applies its special one-cast multiplier to the remaining effective cooldown.

Phong Thế:
- cannot affect the same Phong skill that created it;
- cannot reduce work/crafting/building/recovery timers;
- cannot chain from Mutation secondary effects.

AI should raise the utility of an important/high-cooldown skill while Phong Thế is active.

# 29. Băng Linh Căn — locked combat mechanic

Buff vĩnh viễn theo cảnh giới:

| Cảnh giới | Effect Hit contribution | debuff/control duration |
|---|---:|---:|
| **Thức Tỉnh** | +10 percentage points | +10% |
| **Thuế Biến** | +20 percentage points | +20% |
| **Viên Mãn** | +30 percentage points | +30% |

Effect Hit requires future canonical status-resolution authority.
Do not build a Băng-only private status-hit formula.

## 29.1 Hàn Ấn

Each **Băng-tagged skill cast** that hits a target adds at most:
**1 Hàn Ấn per caster-target per cast**.

AoE:
- each target hit may receive one Hàn Ấn.

Multi-hit:
- repeated hits from the same cast do not add extra Hàn Ấn.

Hàn Ấn:
- lasts **15 seconds**;
- adding a new stack refreshes that caster's stack lifetime;
- at 3 stacks, consume the stacks and trigger Băng Phong/Hàn Trệ.

Normal enemy Băng Phong:

| Cảnh giới | Freeze duration |
|---|---:|
| **Thức Tỉnh** | 1.0s |
| **Thuế Biến** | 1.5s |
| **Viên Mãn** | 2.0s |

After Băng Phong, that target enters a **6-second global Băng-Phong refractory state**.
No caster may add new Hàn Ấn during that refractory window.

Bosses do not become globally immune.
Instead 3 stacks trigger **Hàn Trệ**:

| Cảnh giới | Boss attack interval / cast time | Duration |
|---|---:|---:|
| **Thức Tỉnh** | ×1.15 | 3s |
| **Thuế Biến** | ×1.25 | 4s |
| **Viên Mãn** | ×1.35 | 5s |

Bosses also receive the same 6-second global refractory window.

AI should increase the utility of a Băng skill when a valid target is at 2 Hàn Ấn.

# 30. Dương Linh Căn — locked combat mechanic

Buff vĩnh viễn theo cảnh giới:

| Cảnh giới | All Damage contribution | DoT potency |
|---|---:|---:|
| **Thức Tỉnh** | +8% | +15% |
| **Thuế Biến** | +16% | +30% |
| **Viên Mãn** | +25% | +50% |

## 30.1 Dương Bạo

Dương is a DoT-to-burst conversion build.

A **Dương-tagged direct-damage skill** hitting a target may trigger Dương Bạo if:
- the target has an eligible DoT created by the same caster;
- that target's Dương-Bạo internal cooldown is ready.

Select the caster-owned eligible DoT with the greatest remaining total damage.

Convert the following fraction of its remaining damage into immediate Dương damage:

| Cảnh giới | Remaining DoT converted immediately |
|---|---:|
| **Thức Tỉnh** | 25% |
| **Thuế Biến** | 40% |
| **Viên Mãn** | 60% |

The converted amount is removed from the remaining DoT.
It is not duplicated.

Per-target internal cooldown:

| Cảnh giới | Internal cooldown |
|---|---:|
| **Thức Tỉnh** | 8s |
| **Thuế Biến** | 6s |
| **Viên Mãn** | 4s |

AoE:
- resolves separately per target;
- each target has its own internal cooldown.

Multi-hit:
- one cast may trigger Dương Bạo at most once per target.

Team ownership:
- one disciple cannot consume another disciple's DoT by default.

This requires future DoT state to retain:
- source/caster;
- effect id;
- remaining duration;
- remaining damage or sufficient data to derive it.

Dương Bạo damage cannot trigger another Mutation mechanic.

AI should increase Dương-skill utility when a target has a large amount of caster-owned remaining DoT damage.

# 31. U Minh Linh Căn — locked combat mechanic

Buff vĩnh viễn theo cảnh giới:

| Cảnh giới | Effect Resistance contribution | general Damage Reduction |
|---|---:|---:|
| **Thức Tỉnh** | +15 percentage points | +5% |
| **Thuế Biến** | +30 percentage points | +10% |
| **Viên Mãn** | +45 percentage points | +15% |

General Damage Reduction from independent systems composes through the canonical incoming-damage channel rather than being naively added until it reaches 100%.

## 31.1 Minh Mệnh

Minh Mệnh may trigger **once per encounter**.

When incoming damage would reduce the disciple to 0 HP or below:
- prevent that defeat;
- set HP to a cảnh-giới-tương-ứng fraction of Max HP;
- activate Minh Hộ.

| Cảnh giới | HP after lethal interception | Incoming damage during Minh Hộ | Minh Hộ duration |
|---|---:|---:|---:|
| **Thức Tỉnh** | 15% Max HP | ×0.65 | 2s |
| **Thuế Biến** | 25% Max HP | ×0.50 | 3s |
| **Viên Mãn** | 35% Max HP | ×0.35 | 4s |

It does not reset from healing, target swaps or leaving melee range.
It resets only at a new encounter.

After Minh Mệnh triggers, the autonomous combat AI must immediately reevaluate retreat/survival behavior using the disciple's actual risk/survival policy.

Minh Mệnh is automatic and does not require a separate player button.

# 32. Multiple mutations and full-mutation endpoint

All owned mutations may be active at the same time.

There is no “choose only one active mutation” rule.

A disciple may eventually reach:

- Lôi Viên Mãn;
- Phong Viên Mãn;
- Băng Viên Mãn;
- Dương Viên Mãn;
- U Minh Viên Mãn.

Base-root Resonance does not multiply the five Mutation passive/mechanic values.

There is no 1/2/3/4-mutation resonance ladder.

At exactly cả năm Dị Căn đều Viên Mãn, unlock:

## Ngũ Dị Quy Nhất

Permanent reward:
- **+20% skill effect for all mutation-tagged skills**;
- **+10% resistance to all five mutation elements**;
- eligibility for future explicit Ngũ Dị endgame techniques/content.

This is a derived milestone, not a sixth mutation.

---

# 33. Combat timing / runtime-state ownership

Mutation timers are encounter-local runtime state.

Examples:
- Lôi ready-at timestamp;
- Phong-Thế active-until / ready-at;
- Hàn-Ấn target stacks and refractory-until;
- Dương-Bạo per-target ready-at;
- U-Minh used flag and Minh-Hộ-until.

Do not persistently tick mutation cooldowns for 1,000–3,000 disciples outside combat.

Permanent save data stores mutation identity/mutation_realm/origin/reveal state.
Combat-local timers are created when an encounter starts and discarded when it ends.

This preserves large-population scalability.

---

# 34. Profession / work interaction

Dị Linh Căn does not generically add:
- profession XP;
- forging speed;
- alchemy speed;
- mining action speed;
- crop yield;
- generic work speed.

Natural cross-system consequences are allowed.

Example:
Phong increases canonical Movement Speed.
A miner who physically spends less time travelling/hauling may therefore complete more work over time because the existing work-loop authority already consumes Movement Speed.

A specific crop/recipe/formation may explicitly declare mutation affinity.
That is content-specific data, not a universal hidden profession bonus.

---

# 35. Interaction with Bloodline / Physique / Traits / equipment

Overlap is allowed.

A disciple may combine:
- Thổ 100;
- U Minh III;
- defensive Bloodline;
- defensive Physique;
- defensive equipment.

The result should be extremely durable if the player invested heavily.

Systems must still feed canonical shared channels rather than invent parallel copies of Defense, Damage Reduction, Crit, Effect Hit, etc.

Independent Damage Reduction sources compose through the incoming-damage authority.
Do not sum unrelated percentage reductions until damage becomes negative or zero by arithmetic accident.

---

# 36. Implementation dependencies — locked

Spiritual Root V2 design is closed, but implementation is **not authorized yet**.

Current live combat does not yet provide all primitives required by the locked Mutation mechanics.

Required consumers/dependencies include:

- `base_element` + `advanced_element` skill/technique tags;
- stable cast/source identity;
- canonical Crit and Crit Damage;
- canonical Effect Hit / Effect Resistance;
- source-owned status/DoT state with remaining damage;
- target refractory/control state;
- lethal-damage interception;
- canonical cooldown modification;
- final Defense / penetration / HP / damage channels;
- elemental identity/resistance on monsters.

Some primitives already partially exist:
- skill cooldown;
- cast time;
- movement speed;
- direct skill effect multiplier;
- Burn/Weaken-style combat state;
- incoming-damage multipliers.

Do not create temporary root-only substitute stats merely to ship Mutation early.

When implementation is explicitly authorized, either:
1. include the required combat primitives in that active phase because they are necessary dependencies; or
2. implement only the V2 root data/generation/refinement subset and defer mutation combat activation to the later Skill/Combat V2 phase.

Never expose a mutation mechanic in UI before its real gameplay consumer exists.

---

# 37. Migration from current legacy mutation code

Current legacy RootRefinement mutation behavior is not V2 authority.

Legacy behavior currently includes:
- much higher source-dependent mutation probabilities;
- reveal tied to refinement count/global purity;
- one legacy mutation naming set;
- small generic technique multipliers.

V2 replaces that model.

Migration must:
- preserve deterministic identity where an old save already has a valid revealed/latent mutation;
- map legacy mutation identity to its corresponding V1 branch where possible;
- never reroll an existing hidden mutation during migration;
- replace old reveal/chance rules with the V2 stored identity/state;
- remove old source-dependent 18%/28%/42% mutation generation from V2 characters.

Exact old-save conversion values belong to the implementation phase and must be regression-tested.

---

# 38. Testable invariants

When Spiritual Root V2 is implemented, focused tests must prove at minimum:

1. same seed/source/index generates the same base roots, purities and congenital mutation;
2. root count remains independent from Disciple Quality;
3. per-element purity persists exactly through save/load;
4. reveal never rerolls mutation identity;
5. ordinary refinement is deterministic +1 and consumes exact resources;
6. missing-root creation is deterministic;
7. congenital ordinary generation creates at most one mutation;
8. acquired mutation can eventually produce all five mutations on one disciple;
9. base-root Resonance does not multiply Mutation mechanic/passive values;
10. full five Viên Mãn derives Ngũ Dị Quy Nhất;
11. one cast cannot multi-proc Lôi through AoE/multi-hit;
12. Phong cannot recursively reset its own creator skill;
13. Băng refractory prevents permanent control chains;
14. Dương cannot consume another disciple's DoT;
15. U Minh triggers at most once per encounter;
16. Mutation secondary effects cannot recursively trigger Mutation mechanics;
17. encounter-local timers are deterministic and do not persist as long-lived character cooldown state;
18. profession systems receive no generic hidden Dị-Căn work-speed multiplier.

---

# 39. Spiritual Root V2 closure

Spiritual Root V2 design is now closed for:
- base roots;
- birth distribution;
- per-element purity;
- base buffs/passives;
- perfected-root Resonance;
- five-element combat matchup;
- deterministic refinement;
- adding missing roots;
- congenital mutation rarity;
- Lôi/Phong/Băng/Dương/U Minh V1;
- mutation realms Thức Tỉnh / Thuế Biến / Viên Mãn;
- mutation resources and sources;
- mutation combat mechanics/timing;
- full-five mutation endpoint;
- persistence;
- profession/system interaction;
- combat dependencies;
- migration/test invariants.

Still open only as future content expansion, not as a blocker to the V2 design contract:
- extra mutation branches beyond the V1 five;
- final visual names/colors/icons;
- future environmental/formation content using elements;
- specific endgame Ngũ Dị techniques.

No Spiritual Root V2 gameplay code has been implemented by this design lock.
