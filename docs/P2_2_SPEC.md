# P2.2 — Spiritual Root Quality / Long-Term Growth

Status: IMPLEMENTED / AWAITING RUNTIME GATE

Baseline: P2.1 implementation commit `cc9be52e72b1e787962edaab44319b680805f3b3`.

## Goal

P2.2 explains why two disciples with similar current strength can have very different long-term cultivation trajectories.

A spiritual root is valid only if it changes real cultivation progression, breakthrough probability and recruitment tradeoffs. It is not a decorative rarity label.

## Scope

P2.2 adds quality only. It deliberately does **not** add elemental roots (Kim/Mộc/Thủy/Hỏa/Thổ), techniques, pills, meridians, physiques or hard realm caps.

Four qualities exist:

| Quality | Cultivation multiplier | Breakthrough modifier | Generation weight |
| --- | ---: | ---: | ---: |
| Tạp linh căn | 0.75x | -8 percentage points | 45 |
| Phàm linh căn | 1.00x | 0 | 38 |
| Địa linh căn | 1.20x | +5 percentage points | 14 |
| Thiên linh căn | 1.45x | +10 percentage points | 3 |

Weights affect deterministic generation only; they are not player-facing drop-rate promises.

## No hard destiny cap

Root quality never blocks a realm.

A Tạp-linh-căn disciple may still reach Trúc Cơ, Kim Đan and later realms. The disadvantage is time and breakthrough reliability, not a forbidden ceiling.

This preserves the possibility of a weak-talent disciple succeeding through time, personality, player investment and later systems.

## Deterministic generation

Root generation uses a separate deterministic seed derived from:

- simulation seed;
- stable disciple/candidate id;
- candidate generation index when applicable.

It does not consume the existing recruitment RNG stream.

Therefore enabling P2.2 must not change candidate name, combat power, personality biases or generation order from P1.2/P2.1.

`P22Factory` first creates the complete P2.1 state, then enables spiritual roots and assigns roots to existing disciples/candidates.

Future candidates receive a root through the same separate root generator.

## Cultivation consequence

P2.1 base cultivation remains 8 per CULTIVATE action.

When P2.2 is enabled:

`actual cultivation gain = base cultivation gain × root multiplier`

Examples:

- Tạp: 8 × 0.75 = 6;
- Phàm: 8 × 1.00 = 8;
- Địa: 8 × 1.20 = 9.6;
- Thiên: 8 × 1.45 = 11.6.

The same multiplier is applied to other cultivation-progress sources, including the small combat-victory gain. This keeps one coherent growth rule.

When P2.2 is disabled, P2.1 gains remain exactly unchanged.

## Breakthrough consequence

P2.1 computes stage chance + small HP/stamina condition bonuses.

P2.2 then adds the root modifier before the final probability clamp.

This means root quality changes actual success/failure probability but does not bypass P2.1 breakthrough requirements, cooldowns or failure consequences.

## Recruitment consequence

Candidates expose:

- current combat power;
- root quality;
- cultivation multiplier;
- breakthrough modifier.

The player chooses the tradeoff directly.

Example:

- a currently strong Tạp-root candidate may be useful immediately;
- a weaker Thiên-root candidate may have much stronger long-term growth.

P2.2 intentionally does not collapse this into a single AI-generated score.

Accepted candidates preserve their root quality and immediately use it in the real cultivation system.

## Compatibility contract

- P21Factory and all earlier factories leave `spiritual_roots_enabled = false`.
- Disciple/candidate root fields remain empty on earlier paths.
- P2.2-only serialized fields are emitted only when roots exist/enabled.
- Recruitment legacy RNG is not consumed by root generation.
- Existing P0–P2.1 behavior must remain unchanged when roots are disabled.

## Scale contract

- one root-quality value per disciple/candidate;
- O(1) multiplier/modifier lookup;
- no population scan during cultivation or breakthrough;
- no new graph/table between disciples;
- root generation happens only when a person/candidate needs a root.
