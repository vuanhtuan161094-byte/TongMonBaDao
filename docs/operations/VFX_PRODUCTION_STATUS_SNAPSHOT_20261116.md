## Independent gates
- `CATALOGUED`: data exists, not a native video.
- `DEDICATED_LAB`: isolated Godot visual implementation exists, **not** automatic Godot QA success or owner beauty approval.
- `GODOT_NATIVE_TECH_PASS`: strict exact-SHA tests and native movie, **not** beauty approval.
- `OWNER_VISUAL_APPROVED`: explicit owner's decision on exact Human LAB art. **No** implied immortal/divine tier approval.
- `PVE_INTEGRATION_HOLD / V63_OFF / PHYSICAL_QA_PENDING` apply to all statuses until separate implementation/owner permission.
