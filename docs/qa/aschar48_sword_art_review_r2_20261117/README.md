# AS-CHAR V7 — Sword Art Review R2

Open this folder as a Godot 4.7.2 project, or double-click OPEN_SWORD_ART_REVIEW.cmd.

The page is a 1280×720 Godot-native review, not a production gameplay scene. It compares three separate transparent sword PNG candidates beside the unchanged AS-CHAR-48/49 identity frames. The 52×52 strip matches the current PR #72 map portrait slot; the larger sword render is a detail view.

The identity source frames retain their existing baked weapons. They are shown only for character identification. New sword candidates are not attached to the sprites and do not yet have grip, pivot, per-frame occlusion or animation metadata.

All options remain OWNER_APPROVAL_PENDING; no gameplay or runtime assets changed.
