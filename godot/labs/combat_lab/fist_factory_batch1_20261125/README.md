# Fist Factory batch 1

Data-driven Factory adapters for 15 Human Fist LAB source scenes. The batch reuses first-party SVG, WebP and PNG masters; four missing output atlases were restored from already-tracked deterministic generators and retain their `code-painted` or project-owned derivative provenance. Nine encoded WebP masters are losslessly decoded from the tracked `.b64` sources.

Run `python3 godot/labs/combat_lab/fist_factory_batch1_20261125/build_batch.py` from the repository root to regenerate the decoded source copies, registry rows, Web Review rows and manifest.

All rows remain candidate-only: the ledger source gate is preserved and art approval is pending. The shared native capture is pending for the expanded 15-skill batch. Owner visual review remains pending; PvE remains HOLD. Fist14 uses its R5 source package only; the R7 and R8 G3 failures remain untouched. Only Fist Basic and Mobility remain blocked because no dedicated Human source LAB or sprite master exists in HEAD.
